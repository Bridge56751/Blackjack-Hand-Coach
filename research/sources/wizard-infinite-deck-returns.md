# Expected Returns in Infinite-Deck Blackjack

## Introduction

![Expected Returns in Infinite-Deck Blackjack](https://wizardofodds.com/media/modules/article/images/11/blackjack5-large.jpg)

The following tables display expected returns for any play in [blackjack](https://wizardofodds.com/games/blackjack/) based on the following rules: dealer stands on a soft 17, an infinite deck, the player may double after a split, split up to three times except for aces, and draw only one card to split aces. Based on these rules, the player's expected value is -0.511734%.

To use this table, look up the returns for any given play, the one with the greatest return is the best play. For example suppose you have two 8's and the dealer has a 10. The return by standing is -0.5404, by hitting is -0.5398, doubling is -1.0797, and by splitting is -0.4807. So splitting 8's you stand to lose the least, 48.07 cents per original dollar bet, and is thus the best play.
